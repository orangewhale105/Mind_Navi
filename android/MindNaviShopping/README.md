# Mind_Navi 買い物リスト（Android）

## バージョン
- 1.2（versionCode 3、2026-11-08）：名前を Mind_Navi に変更（旧称 TaskMap）。アプリの識別名が jp.mindnavi.shopping に変わったため、旧版（TaskMap 買い物リスト）には上書きできない。旧版をアンインストールしてから入れ、データファイルを選び直す
- 1.1（versionCode 2）：PC版に合わせて 個数・小計・総計 を追加。画面の欄は PC版と同じ（データファイルの view.groceries.layout を読む）。必要度はタップで一覧から選ぶ（表示されない不具合を修正）
- 1.0（versionCode 1）：最初の版

更新は、新しい APK をそのままインストール（上書き）してください。同じ署名なので設定（選んだファイル）は残ります。

PC版 Mind_Navi と同じデータファイル（.json）を直接読み書きする買い物リストアプリです。
買い物リストを別ファイルに分けず、**1つのデータファイルの `view.groceries` 部分だけ**を書き換えます。それ以外の部分（タスク・カレンダーなど）は読んだ内容をそのまま書き戻します。

## インストール（APK）
1. MindNaviShopping.apk をスマホに入れる（Googleドライブに置いてスマホで開く、など）
2. 開くと「提供元不明のアプリ」の許可を求められるので、そのアプリ（ドライブ／ファイル）に許可してインストール
3. Play プロテクトの警告が出たら「インストールする」を選ぶ（個人で作ったアプリのため）
- Android 8.0 以上

## 自分でビルドする場合
1. Android Studio（Koala 以降）で、このフォルダを「Open」で開く
2. Gradle の同期が終わったら ▶ Run（実機は USB デバッグを ON）
   - APK だけ欲しい場合: Build → Build App Bundle(s) / APK(s) → Build APK(s)
- 必要: Android 8.0 以上、JDK 17（Android Studio 同梱のもので可）

## 使い方
1. 初回起動で「ファイル」→ Google ドライブの「Mind_Navi」フォルダにあるデータファイル（.json）を選ぶ
   （PC版の［ファイル］→［データの保存フォルダ（Googleドライブ）…］で作るフォルダ。ファイルを移したら選び直す）
2. 以後は自動でそのファイルを開きます（アプリに戻るたびに再読込）
3. 買い物リスト：
   - 一番下の行に品名を入力して確定 → 追加（定番に同じ品があれば価格・必要度を引き継ぎ）
   - 品名・価格はその場で直接編集、必要度はタップで 高/中/低 を選択（初期値 中）
   - チェック＝購入。購入履歴に記録され、週/月/年の購入回数に反映
   - 回数欄をタップ → 定番に登録 / 削除
   - 「購入済みを片付ける」でチェック済みを一覧から外す
4. 定番タブ：「＋」で買い物リストへ追加、長押しで削除、一番下の行で新規登録
5. 変更は約1.5秒後に自動保存（アプリを閉じたときも即保存）

## PC版との同時利用
- 保存直前にファイルを読み直し、買い物リスト部分だけ差し替えるので、PCで編集したタスク等を消しません
- PC版は、スマホで変更されたのが買い物リストだけなら自動で取り込みます（フォーカス時・20秒ごと・買い物リストを開いたとき・自動保存時）
- Google ドライブの同期には数秒〜数十秒かかります。両方で同時に買い物リストを編集した場合はPC側でマージします

## 署名鍵（更新版を上書きインストールするため）
- 鍵 mind_navi.keystore（別名 taskmap。旧名のまま）。鍵とパスワードはリポジトリに入れず、別の場所に保管する（ビルド方法は tools/build_apk.sh の冒頭）
- 同じ鍵で署名した APK なら、データ（選んだファイルの設定）を残したまま上書き更新できます
